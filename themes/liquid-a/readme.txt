液态玻璃质感的高级 WordPress 主题，提供毛玻璃效果、苹果官网风格、完全响应式。

== 描述 ==
LiquidGlass 是一款现代、简约、富有科技感的主题，采用液态玻璃效果，让您的网站看起来像 Apple 官网一样精致。

特性：
- 液态玻璃毛玻璃效果
- 自定义主题颜色、标题颜色
- 博客流/杂志流两种首页布局
- 滚动动画，可一键开启/关闭
- 完全响应式，适配所有设备
- 支持 WooCommerce 基础模板
- 中文翻译友好，附带中文注释

== 安装 ==
1. 将 `liquidglass` 文件夹上传至 `/wp-content/themes/` 目录。
2. 在 WordPress 后台“外观 -> 主题”中激活 LiquidGlass。
3. 进入“外观 -> 自定义”调整颜色和布局。
4. 添加分类和文章开始使用。

== 经常问的问题 ==
= 如何关闭滚动动画？ =
在外观 -> 自定义 -> 首页布局中可以关闭动画。

= 如何修改颜色？ =
在外观 -> 自定义中可以修改主题主色、强调色、标题颜色等。
